# 🎓 Campus Buddy<br>
Campus Buddy is a Telegram-based student assistant built with **Django REST Framework** and **Python Telegram Bot**. It allows students to securely log in using their college credentials and access important academic information directly from Telegram.

# Features

-  JWT Authentication
-  Student Profile
-  Attendance Tracking
-  Semester Timetable
-  College Notices
-  Telegram Bot Integration
-  Secure Telegram Account Linking
-  Login & Logout System
-  Interactive Menu

---

# Tech Stack

- Python
- Django
- Django REST Framework (DRF)
- PostgreSQL
- Simple JWT
- Python Telegram Bot
- Git & GitHub
